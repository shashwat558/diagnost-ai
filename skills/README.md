# Diagnost AI skills

Installable skills for AI coding agents.

## agent-analytics

Auto-instruments an AI agent codebase with Diagnost production analytics:
OTel-native tracing, PII-redacted checkpoints, failure clustering, drift
alerts and self-verifying auto-PRs.

```bash
npx skills add shashwat558/diagnost-ai --skill agent-analytics
```

See [`agent-analytics/SKILL.md`](./agent-analytics/SKILL.md) for the full
instruction set the agent will follow.
